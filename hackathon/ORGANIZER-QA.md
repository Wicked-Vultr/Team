# Organizer Q&A

Bring these questions to [Discord](https://discord.gg/lablabai). Add each answer with a thread link or recording timestamp, then update the affected build decision.

## Resolve before committing the architecture

| Topic | Ask | Decision affected |
|---|---|---|
| Existing accounts and credits | How do existing Vultr customers receive credits? What VSI subscription/usage charges do they cover, and what limits apply? | Account setup and available build capacity. |
| Credentialed actions | For Blast Radius Zero, may a trusted adapter outside the sandbox hold scoped credentials and execute approved API operations? | Customer/vendor authorization design. |
| Customer-local access | May a customer-controlled connector run outside Vultr while the controller, web app and untrusted execution remain on Vultr? | Local connector versus a simulated customer environment. |
| Both challenges | Can one project qualify for both challenges, and which selection does the form require? | Entry scope. |
| Judging | Who are the judges? What weights, track prize pools and technical checks apply? | Demo priorities and review preparation. |
| Schedule and replay | Which published kickoff/deadline times govern? Where will kickoff and Discord Q&A recordings be available? | Team schedule and recording access. |
