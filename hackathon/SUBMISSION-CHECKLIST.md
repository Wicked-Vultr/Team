# Submission checklist

Choose the challenge in the [requirements review](REQUIREMENTS-REVIEW.md). Session times and the deadline are in the [README](../README.md).

## Build and entry

- [ ] Confirm team registration, membership and Discord access.
- [ ] Select the challenge in the event form.
- [ ] Deploy the public web app and central backend on Vultr.
- [ ] Publish the repository with setup, sample input and expected results.
- [ ] Explain the use case, architecture and Vultr services in the product README.
- [ ] Prepare descriptions, tags, cover, PDF slides and recorded demonstration.
- [ ] Apply the event's licensing terms and include third-party notices.

## Blast Radius Zero

- [ ] Route agent LLM calls through Vultr Serverless Inference.
- [ ] Execute generated code/browser actions in a separate Vultr sandbox.
- [ ] Keep credentials in trusted services outside the sandbox.
- [ ] Enforce time/memory limits and cleanup after every task.
- [ ] Retain executed output and checks.
- [ ] For browser automation, capture screenshots, vision checks and final-action approval.
- [ ] Record a containment example in the demo.

## Powering the Future of Work

- [ ] Complete a realistic enterprise workflow across several connected steps.
- [ ] Make the browser flow clear from input to usable result.
- [ ] Demonstrate the outcome against the user's acceptance criteria.

## Repository and release

- [ ] Link the app, video and slides from the README.
- [ ] Document install/run/deploy commands and actual runtime configuration.
- [ ] Include placeholder environment variables, dependency locks and deployment files.
- [ ] Describe operating limits and identify simulated integrations.
- [ ] Provide a reproducible sample and relevant failure/authorization checks.
- [ ] Identify the submitted commit and link any component repositories.
- [ ] Open the app, repo and media in a signed-out browser.
- [ ] Check slide/video legibility and the final form's media limits.
- [ ] Submit on lablab before the deadline and save the confirmation URL.
- [ ] Optional: publish a Vultr Community showcase.
